# 一键启动《Minecraft：Java版》V1.6正式发布

## 功能特点

- **目前自带1.12.2和2015愚人节版本**
- **自带32位java环境，无需额外下载任何文件，抛弃繁琐的配置和安装过程，启动方便，零基础电脑小白也可轻松使用**

## 如何使用

下载后**解压**到您的U盘设备**即可使用**！
> 需要注意的是，您可能**无法直接运行**从GitHub链接下载的源代码，您需要将源代码中的内容**复制到一个新的空白批处理文件**后才能使用。
> （已构建的exe版本及123网盘链接**不受此影响**）
